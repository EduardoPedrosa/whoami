# Assets e validação visual

A arte `frontend/public/identity-cards.webp` foi regenerada com a ferramenta integrada `imagegen` para a paleta azul e comprimida para WebP (1100 × 1100). O original foi preservado no diretório de imagens geradas do ambiente. Arte decorativa; não participa do estado do jogo.

Direção: azul cobalto claro `#819cff`, fundo azul noturno `#0b1020`, cartas e peças em azul e branco. A ilustração mantém o astronauta, a interrogação e o alienígena, agora azul.

Os screenshots documentam a revisão visual. A fonte Outfit e a Geist Mono são distribuídas pelos pacotes Fontsource, com suas licenças OFL nos pacotes. Ícones são Phosphor; os componentes interativos de base foram gerados pela CLI oficial do shadcn/ui e adaptados aos tokens do projeto.
